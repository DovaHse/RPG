Projeto de Java POO simulando um combate de RPG de turnos.

Objetivo do projeto: feito para praticar e melhorar os conceitos de JAVA POO que eu aprendi nesses últimos meses.

Esse projeto simples simula um combate de 3 heróis (guerreiro, mago e ranger) contra um chefe usando comandos simples no terminal da IDE.

Tecnologias e Conceitos Aplicados:
- Java (JDK)
- Orientação a Objetos (POO): Herança, Polimorfismo, Classes Abstratas e Encapsulamento.
- Coleções (List, ArrayList): Gestão dinâmica dos participantes e estados de vida.
- Tratamento de Exceções (try-catch): Validação defensiva de inputs do utilizador para evitar que o jogo vá abaixo caso sejam introduzidos caracteres inválidos nos menus.

Como executar o projeto:
- Tenha o JAVA JDK instalado no seu PC.
- Abre a pasta do projeto na tua IDE favorita (IntelliJ, Eclipse, VS Code, etc.).
- Faca a execução diretamente no main.java
- Acompanha o combate diretamente no terminal da sua IDE e faca suas próprias escolhas.
